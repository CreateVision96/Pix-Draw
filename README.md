# PIX DRAW

PIX DRAW is a simple pixel art drawing web app made with HTML, CSS, and JavaScript.

you can draw pixel art on it and save it as PNG

## Features

- Pencil tool
- Erase tool
- Fill tool
- Color picker tool
- Adjustable grid size
- Adjustable canvas size
- Undo and Redo

### Grid sizes

- 8 x 8
- 16 x 16
- 32 x 32
- 64 x 64

## USE OF AI

- Ai was only used for debugging in JavaScript
- The code doesnt have any direct lines from AI
- HTML and CSS was fully written by me

The icons are from https://lucide.dev/
